# Contributing to Wemute

Thanks for helping. Bug reports, conversions that fail, and pull requests are all welcome.

- Open an issue first for larger changes, so we can agree on the approach.
- Keep pull requests focused, and describe what the change does and how you checked it.
- Run `uv run pytest` before submitting.
