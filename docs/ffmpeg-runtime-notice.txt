Enabled external libraries:

- LAME / libmp3lame — LGPL-2.0-or-later
  https://sourceforge.net/projects/lame/files/lame/
- Opus — BSD-3-Clause
  https://github.com/xiph/opus
- libvpx — BSD-3-Clause
  https://chromium.googlesource.com/webm/libvpx

Wemute invokes FFmpeg and FFprobe as separate executables. Wemute does not
modify FFmpeg. Replacement runtime binaries can be placed in Wemute's bundled
runtime directory or selected through WEMUTE_FFMPEG and WEMUTE_FFPROBE.
